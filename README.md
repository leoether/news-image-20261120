A program that draws one newspaper front page summing up the world's news of
Friday 20 November 2026: the Trump–Xi–Putin summit in Shenzhen, Cyclone Akvan
nearing Odisha, the ICJ's genocide ruling on Myanmar, Anthropic's record IPO,
Fiji's drought disaster, and the day's sport.

Run it (Node 22, standard library only, no network):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes `out/entry.png` — 1024×1024, deterministic: two runs produce
byte-identical output.
